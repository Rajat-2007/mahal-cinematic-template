## 🚀 How to Run in VS Code

1. Extract `mahal-cinematic-template.zip`.
2. Open **VS Code** -> `File` -> `Open Folder...` -> Select `mahal-cinematic-template`.
3. Right-click `index.html` -> **"Open with Live Server"**.
4. Scroll mouse wheel to fly the 8-stage 3D drone camera, click on glowing 10D hotspots to open drawers & window drone views!
